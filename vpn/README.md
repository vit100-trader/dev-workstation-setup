# VPN Setup

## Instructions

See the Confluence page for full VPN setup instructions:
- [AWS Client VPN Transition to AS24 Okta Authentication](https://trader.atlassian.net/wiki/spaces/CLOUD/pages/4891476045/AWS+Client+VPN+Transition+to+AS24+Okta+Authentication)

## Downloading VPN Profiles

Download VPN profiles from the AWS Client VPN Self-Service Portal:
- [https://self-service.clientvpn.amazonaws.com/](https://self-service.clientvpn.amazonaws.com/)

## Client Software

Install the AWS VPN Client:
- [Download AWS VPN Client](https://aws.amazon.com/vpn/client-vpn-download/) (Windows version)

Import downloaded `.ovpn` profiles via **File > Manage Profiles > Add Profile**.
